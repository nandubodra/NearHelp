# Node / Express / SQLite app for NearHelp

## Getting started

1. Install dependencies:
   npm install
2. Start the app:
   npm start
3. Open the app in your browser:
   http://localhost:3000

## Features

- User registration and login
- SOS creation, assignment, chat, AI assistant and resolve flow
- Guardian management
- Resource map data
- History and moderation views
- Socket.IO realtime updates
- Offline queue simulation and reconnect sync

## Environment

Copy `.env.example` to `.env` if you want custom settings.
